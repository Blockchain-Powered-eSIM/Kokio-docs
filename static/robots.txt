# robots.txt for docs.kokio.app
#
# Ported from Kokio-web/app/robots.ts, which is the maintained list. Keep the
# two consistent or the stance reads as accidental rather than decided.
#
# The stance is yes: retrieval crawlers and training crawlers both get
# everything. The wildcard group below is what actually grants that, including
# to every crawler not named here. The named groups exist so the decision is
# auditable, and so blocking any one of them later is a one-line edit rather
# than a research task.
#
# One rule for adding an entry: the operator publishes a crawler page naming
# the token. That keeps the list checkable and finite. It is deliberately not
# exhaustive and cannot be, because most labs publish no user agent at all.
#
# WARNING, if you ever add a Disallow: groups in robots.txt are independent. A
# crawler that matches a named group reads only that group and never sees the
# wildcard rules. A Disallow written once here applies only where it is
# written, so it has to be repeated in every group below.

# Common Crawl. The most consequential entry here for open-weight models: most
# open training sets, C4, RefinedWeb, FineWeb and Dolma among them, are built
# from Common Crawl rather than from their own crawls. Allowing it is close to
# irreversible, because a page that lands in the archive is copied into derived
# datasets that have no recall mechanism.
User-agent: CCBot
